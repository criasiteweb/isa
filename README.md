# Isa Carvalho Imóveis

Link na bio da corretora Isabella Carvalho (CRECI-SP 195.448), especialista em
financiamento habitacional pela Caixa Econômica Federal e no programa
Minha Casa Minha Vida, atuando no Grande ABC, Zona Leste e São Paulo.

## O que o site faz

- Contato direto por WhatsApp, com mensagem já preenchida por intenção
- Simulador de faixa do Minha Casa Minha Vida pela renda familiar, com o
  resultado enviado junto na conversa do WhatsApp
- Galeria das entregas de chave já realizadas, com ampliação em tela cheia
- Perguntas frequentes e formulário curto de captação de lead

## Estrutura

```
index.html      página única, sem dependências externas além do Google Fonts
fotos/          foto de perfil, imagens de apoio e entregas de chave
logos/          espaço para caixa.png e mcmv.png (opcional)
```

Não há build. É HTML, CSS e JavaScript puro, servido como arquivo estático.

## Publicação

O site funciona em qualquer hospedagem estática. No GitHub Pages, basta ativar
em Settings > Pages apontando para a branch principal na raiz.

## Dados do programa

As faixas usadas no simulador seguem as regras vigentes em 2026 e estão
declaradas na página como estimativa. O valor final depende da análise da
Caixa Econômica Federal.
